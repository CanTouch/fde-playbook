# Glossary

- **Forward deployed engineer (FDE):** an engineer embedded in a customer's operation who owns a measured outcome.
- **ERP (enterprise resource planning):** software that runs back-office operations such as finance, orders, inventory, purchasing and payroll. Examples: NetSuite, SAP, Microsoft Dynamics 365, Oracle Fusion, Workday, Odoo.
- **CRM:** software that tracks customers and sales conversations. Examples: Salesforce, HubSpot.
- **System of record:** the system that holds the official data. A CRM or ERP for larger firms, or a spreadsheet or database for a small shop.
- **Process mining:** reading system activity logs to reconstruct how work actually flows, including loops.
- **Human API:** using interviews to extract procedures that live in people's heads.
- **Touch time:** minutes of real work on an item.
- **Elapsed time:** calendar time the item exists from start to finish.
- **Idle days:** days an item sits with nobody working on it.
- **Straight-through processing:** the share of items handled with no human touch.
- **Background agent:** an agent that runs a recurring workflow on its own and alerts a person on exceptions.
- **Sidekick:** a chat copilot a person talks to while working.
- **Human in the loop:** a step where a person makes the final call.
- **Baseline:** the measured starting values of the metrics, recorded before building.
- **Value slice:** a fee set as a share of the value the project creates.
- **Carry:** an ownership share in the increase of a company's value, used in private equity deals.
