# Case study template

Get written permission from the client before you publish anything. Describe the client by trade and region unless they agree to be named.

## 1. The business and the process
Two sentences: what the business does, which single process was in scope, and who owned it.

## 2. Before
- The map as the client described it.
- The map as it actually ran, with loops and idle time marked.
- Baseline table and the date it was measured.

| Metric | Before |
|---|---|
| | |

## 3. What changed
- The four-bucket sort: how many steps were deleted, moved to plain code, given to an agent, kept with a person.
- What the agent does and what a person still decides.
- Which of the client's existing tools it runs inside.

## 4. After
- The same map redrawn.
- The same metrics, measured the same way, with the date.

| Metric | Before | After | Change |
|---|---|---|---|
| | | | |

## 5. The owner, in their words
One or two sentences from the process owner.

## 6. What it costs to run
Monthly running cost, listed by component (hosting, model usage, messaging, tools).

## 7. What was left undone
One honest line about what the project did not fix or what you would change.
